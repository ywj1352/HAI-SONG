# 第二集素材目录

## 命名规则

图片文件使用分镜编号命名：

```text
S01-P01.png
S01-P02.png
...
S08-P03.png
```

完整素材路径为：

```text
章节/02-议处之后/素材/Sxx-Pxx.png
```

## 当前状态

本集已完成正文、分镜和绘图提示词，实际图片尚未生成。生成图片后直接放入本目录，不要修改分镜编号。

## 图片要求

- 默认尺寸比例为 9:16。
- 推荐输出 PNG；人物、海图和量水木尺尽量保留清晰边缘。
- 不在图片内生成大段对白、标题、诏榜或水印，文字由正文或后期字幕处理。
- 同一角色优先参考本目录上级章节的角色设定与本集 `角色设定.md`。
- 同一场景优先参考本集 `场景设定.md`，并保持第一集泉州港、船厂、官署和临安朝堂的材质连续性。
- 如果生成了多版图片，使用后缀标记，例如 `S01-P01-v2.png`；最终采用版本仍在分镜脚本中引用为 `S01-P01.png`。
